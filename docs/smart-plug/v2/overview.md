# Tasmota V2 Overview

These pages cover the newer Tasmota interface used on newer Smart Hut plugs.

The existing Tasmota pages elsewhere in the Smart Plug docs are still valid for older shipped plugs with the earlier UI.

## What is different

- The main menu now exposes dedicated buttons for `WiFi`, `MQTT`, `Matter`, `Information`, and `Advanced`.
- Advanced options such as `Tools` and `Firmware Upgrade` sit behind the `Advanced` page.
- The setup flow is still the same at a high level, but the page layout differs from the older firmware.
