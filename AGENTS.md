# AGENTS

## Stack
- Single-package Docusaurus 3 site; use `npm`, not `yarn` (`package-lock.json` is checked in, no Yarn lockfile).
- Node requirement is `>=18` in `package.json`.

## Commands
- Install: `npm install`
- Dev server: `npm start`
- Production verification: `npm run build`
- Clear generated cache if routing/content changes act stale: `npm run clear`

## Deployment
- GitHub Actions deploys to GitHub Pages on pushes to `main` via `.github/workflows/deploy-pages.yml`; keep the site buildable on Linux with `npm ci && npm run build`.

## Routing And Content
- Docs are mounted at site root because `docs.routeBasePath` is `'/'` in `docusaurus.config.js`; do not assume the default `/docs/...` URLs.
- `src/pages/*` is still enabled, but it renders under `/pages` because `pages.routeBasePath` is `'/pages'`.
- `sidebars.js` is fully autogenerated from `docs/`; control nav order with filesystem layout, `_category_.json`, and doc frontmatter like `sidebar_position`.
- `blog/` exists in the repo, but the blog plugin is disabled with `blog: false`, so blog content is not part of the site unless config changes.

## Generated Files
- Do not edit `.docusaurus/` or `build/`; both are generated and ignored.

## Verified Gotcha
- Re-run `npm run build` after any link or route change because `onBrokenLinks` is set to `throw` and will fail the GitHub Pages deploy workflow on broken internal links.
