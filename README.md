# Website

[![Deploy GitHub Pages](https://github.com/Smart-Hut/documentation-site/actions/workflows/deploy-pages.yml/badge.svg)](https://github.com/Smart-Hut/documentation-site/actions/workflows/deploy-pages.yml)

This website is built using [Docusaurus](https://docusaurus.io/), a modern static website generator.

## Installation

```bash
npm install
```

## Local Development

```bash
npm start
```

This command starts a local development server and opens up a browser window. Most changes are reflected live without having to restart the server.

## Build

```bash
npm run build
```

This command generates static content into the `build` directory and can be served using any static contents hosting service.

## Deployment

Deployments are handled automatically by GitHub Actions on pushes to `main`.
